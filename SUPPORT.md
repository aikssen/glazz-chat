# Support

Glazz is a portfolio-grade reference project maintained by one person. There is no
commercial support and no hosted service.

## Before opening anything

Most questions are answered by the documentation:

| Question                                 | Where to look                                                                |
| ---------------------------------------- | ---------------------------------------------------------------------------- |
| How do I run the stack?                  | [README](./README.md#run-the-complete-stack)                                 |
| The composer is disabled or reconnecting | [README troubleshooting](./README.md#troubleshooting)                        |
| What does the product actually do?       | [Product capabilities](./docs/product-capabilities.md)                       |
| How is it built?                         | [Technical architecture](./docs/technical-architecture.md)                   |
| Why was something designed this way?     | [Architecture decisions](./docs/adr/)                                        |
| What is done and what is not?            | [TASKS.md](./TASKS.md)                                                       |
| Is it safe to deploy publicly?           | [Security and production readiness](./docs/security-production-readiness.md) |
| How do I contribute?                     | [CONTRIBUTING.md](./CONTRIBUTING.md)                                         |

The full index is [docs/README.md](./docs/README.md).

## Where to ask

- **A bug**: open a [bug report](https://github.com/aikssen/glazz-chat/issues/new/choose).
- **An idea**: open a feature request. Check [TASKS.md](./TASKS.md) first — it may
  already be planned or explicitly out of scope.
- **A question**: open a discussion if enabled, otherwise an issue.
- **A vulnerability**: never in a public issue. Follow [SECURITY.md](./SECURITY.md).

## What to expect

Issues are reviewed as time allows, with security reports first. An issue may be
closed as out of scope when it conflicts with the documented product scope or an
accepted architecture decision — that is not a judgment on the idea.

Glazz is pre-1.0 and not approved for public production traffic. Requests for help
running it as a public multi-user service are out of scope until the production
milestone is complete.
